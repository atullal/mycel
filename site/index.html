Messaging,

Mycel is an open-source messenger. Chat over local Wi-Fi, connect across the internet, or let nearby devices carry a message until it reaches a friend.

Inside a conversation

Reply to a photo, leave a voice note or start a group call with up to eight people. If a file transfer gets interrupted, it picks up where it left off.

Your first chat

Start with two devices on the same Wi-Fi. Each device has its own identity, so there’s no account to create.

  1. Open Mycel on both devices

    Install the same build on each. Allow local network access when prompted. In Profile, give each device a name you’ll recognize.

  2. Find each other

    Open Nearby and choose Add beside the other device. Connecting from farther away? Exchange contact codes instead.

  3. Send a hello

    In Messages, choose New conversation, select your contact and choose Start chat. If your hello arrives in Requests, the recipient can accept it and reply.

Where does a message go?

On the same Wi-Fi, your devices can talk even if the router loses its internet connection. Open Network to see which path Mycel is using.

Across the internet, Mycel tries a direct connection first. If the devices can’t reach each other directly, a relay can pass their encrypted traffic along. A device running Mycel can also hold a sealed message for someone who’s offline.

Before you rely on it

Mycel is an experimental preview.

  • The cryptography and the trust layer have not had an outside audit. Do not use Mycel yet for anything that must stay secret.
  • Everyone you talk to must run the same version. The format on the wire still changes between versions.
  • Your device’s key is your account. If you lose the device, there is no recovery.
  • macOS and iPhone have run on real devices. Windows and Linux have only run in automated tests, and Android only in an emulator.
  • A sleeping iPhone or iPad receives nothing until Mycel is opened again. Waking it would need a push server, and Mycel has none.

Read about the architecture, supported platforms and security specification.

Build on Mycel

The messenger is an app built on the Mycel runtime. The runtime manages device keys, storage and connections. Apps use a TypeScript client or React hooks to work with it.
