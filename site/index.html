Mycel

Private messaging with no server. Chats, files and calls go straight between devices, and through other devices when there is no direct path.

How it works

No server holds your messages

Each device keeps its own keys, encrypts end to end and checks everything it receives. To cross the internet, Mycel by default uses public relay and lookup servers run by n0, the team behind Iroh, which see only ciphertext. Switch them off and devices find each other through the BitTorrent DHT and relay for one another.

It works with no internet

Devices on the same network, in Bluetooth range, or joined by peer-to-peer Wi-Fi or a cable talk to each other directly. A Local only mode never contacts the internet at all.

Every device carries for the others

Devices pass each other's sealed messages along, over several hops if that is what it takes, and hold them for someone who is offline. An always-on device you choose, a keeper, can store and serve a chat without being able to read it.

Membership is signed, keys rotate

Every chat has a signed record of who belongs to it, and removing someone changes the key. Keys are sealed to each member with X25519 combined with ML-KEM-768, a post-quantum scheme, and are replaced on a schedule.

Chat, files and calls

Direct chats and groups, replies, edits, reactions and voice notes. Files of any size, sent in pieces that are checked as they arrive and resumed where they stopped. Voice and video calls, one to one or in groups of up to eight.

Open from top to bottom

The apps, the protocol and the tests are in one repository under the MIT and Apache 2.0 licences. The security specification says what is defended and what is not.

Before you rely on it

Mycel is an experimental preview. It works, and it is tested, but it has not earned your trust yet.

  • The cryptography and the trust layer have not had an outside audit. Do not use Mycel yet for anything that must stay secret.
  • Everyone you talk to must run the same version. The format on the wire still changes between versions.
  • Your device's key is your account. If you lose the device, there is no recovery.
  • macOS and iPhone have run on real devices. Windows and Linux have only run in automated tests, and Android only in an emulator.
  • A sleeping iPhone or iPad receives nothing until Mycel is opened again. Waking it would need a push server, and Mycel has none.
