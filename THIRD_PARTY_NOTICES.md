### Rules for vendored code

- Read the crate's `MYCEL_PATCH.md` before changing anything under `vendor/`.
- Keep changes minimal, mark them `MYCEL PATCH`, and describe them in
  `MYCEL_PATCH.md`, with a test.
- Never remove upstream licence files or copyright headers.
- Drop a patch, and the vendored copy, once upstream ships the fix.

## First-party assets

These are original to Mycel and covered by the project licence:

- App icons: `apps/host/public/mycel.svg` and the PNG, ICNS and ICO renderings
  in `apps/host/src-tauri/icons/` and `apps/host/src-tauri/gen/`.
- Screenshots in `docs/screenshots/`.
- WebAssembly rules fixtures in `crates/mycel-rules/fixtures/`, built from
  `rules/` with `rules/build.sh`.

The apps bundle no fonts and no sounds: the UI uses the platform's system
fonts, and notifications use the system's default sound.

## External data not in this repository

The benchmarks use third-party tools and datasets (for example The ONE
simulator and the CRAWDAD contact traces). `bench/fetch.sh` downloads them into
`bench/external/` and `bench/data/`, which are gitignored. They are not
redistributed here, and their own licences apply.
